## Getting Started

1. **Authentication**: Start with [Authentication](overview/authentication.md) to understand how to authenticate
2. **Environment Setup**: Configure your environment using [Environment Configuration](overview/environment.md)
3. **Choose Your Category**: Navigate to the relevant category based on your use case
4. **Browse Endpoints**: Use the [Complete Endpoint List](reference/endpoints.md) to find specific endpoints
5. **Test with Examples**: Use [CURL Examples](utils/curl-examples.md) to test API calls

## API Statistics
- **Total Endpoints**: 626
- **Categories**: 6 main categories
- **Authentication**: Bearer Token
- **Base URL**: `https://api-uk.kurtosys.app` (configurable)
- **Content Type**: `application/json`
